#  Spaza Supply: Digital Marketplace Prototype

**Project:** JGA Prototype for SA Township Spaza Shops  
**Institution:** Tshwane University of Technology (TUT)  
**Course:** Diploma in Computer Science (First Year, 2026)  
**Team:**  Teens in Tech
##  Overview
Spaza Supply is a digital ordering prototype designed to help township spaza shops streamline stock procurement, bulk pricing, and shared logistics. It addresses critical supply chain issues like high transport costs and the inability to buy in bulk.

## From Java to Web: How We Built It
We started by writing the core logic in Java (`SpazaSupplyMenu.java`) to handle complex financial calculations. To make it user-friendly, we converted it into a web interface using two key resources:
1. **High School Foundation:** I have a **Distinction in Computer Applications Technology (CAT) in the NSC finals**, providing a strong background in HTML and web design.
2. **AI Assistance:** We used AI to bridge the gap, helping translate our Java backend math into responsive HTML/JavaScript for the web.

## ⚙️ Key Features
*   **Bulk-Pricing Logic:** Simulates cooperative buying savings.
*   **Delivery Incentives:** Dynamic delivery fees (e.g., free delivery over R500).
*   **Financial Calculators:** Automated formulas for selling price, revenue, net profit, and break-even quantity.
